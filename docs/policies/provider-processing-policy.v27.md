# Provider Processing Policy v27

Canonical authority: [v27 JSON](provider-processing-policy.v27.json), validated against its [exact schema](provider-processing-policy.v27.schema.json). This immutable ordinary-production successor of [v26](provider-processing-policy.v26.json) is selected by [active set v19](active-policy-set.v19.json). It encodes the four [Owner decisions recorded on #1071 on 2026-10-24](https://github.com/zhouy1017/ai7-harness/issues/1071), under [ADR 0095 §§2–6](../adr/0095-make-procedures-the-central-object-govern-concurrent-execution-and-use-dsh-as-the-complex-task-harness.md), [ADR 0094 §§4, 6](../adr/0094-unified-multi-provider-runtime-global-learning-agent-and-word-track-changes-intake.md) and [ADR 0079 §4.4](../adr/0079-record-the-owner-s-decisions-of-2026-09-10-on-storage-policies-export-egress-providers-and-samplebooks.md).

## The four decisions

1. **Review synthesis (Owner decision 1).** The review rule adds `transmissions.plusOneCrossUnitSynthesisTurn: true`, the same bound used by writing and evaluation. The existing synthesis eligibility and contract-retry declaration remain. A synthesis turn counts in the authorized Run's transmission bound.
2. **Book-less Global Agent dialogue (Owner decision 2).** `ordinary-production-global-agent-dialogue` covers deliberate ask, continue and regenerate attempts without a Book. Its `source` admits explicitly listed eligible memory and preference revisions plus the editor's own words, with revision pins rechecked before transmission. It uses the editor's own configured Fast Interaction Role, requires disclosure of what is sent and keeps categories for bookkeeping (`outboundCategoryRestriction: "none"`). This rule sends those eligible sources as they are: both house-people and internal-note redaction filters are false, as the Commander recorded when applying decision 2. Source eligibility still belongs to learning admission. The session grants no whole-library, manuscript or cross-Book read authority. A credential remains outside model-visible material.
3. **Per-kind Background Processing Enrollment (Owner decision 3).** The separate `enrolled-background-processing` rule lists exactly `learning-curation` (F-05), `material-index` (F-08), `review-reduction` (F-19b) and `factual-recheck` (F-04). Its `backgroundProcessingEnrollment.enrollableKinds` requires `mandatoryCeiling: true` on each kind. The enrollment is active, matching and revocable; every dispatch still needs its exact plan, source scope, binding and authorization, with the ceiling evaluated before dispatch. The existing enrolled baseline analysis rule remains unchanged. Merely opening a page or importing a file creates no authority.
4. **Sub-agents (Owner decision 4).** Root `subAgents` requires declaration in the Plan Envelope. A sub-agent inherits the parent's scope, binding, policy and ceiling, passes the same final payload gate and counts inside the parent attempt's transmission bound. It creates no independent AI7 Task, Run or decision record.

## Selection and implementation

Trusted source-checkout launch authority selects active set v19, which pins v27's exact path and SHA-256. The carrier and launch resolver pin the set's exact bytes. Missing, unknown or changed declarations deny processing. The launch reads the declarations; F-05 p2, F-06 p2, F-17a and F-18c own their execution. Eligibility itself starts no processing and supplies no missing capability.

All other v26 terms remain, including its model table baseline, independent Main/Fast bindings, connection test, execution defaults, transport bounds, local tools, research and bounded review instructions. Development-ci v1, fixture-recording v2, developer-live v24 and External Export v2 keep their exact pins. Every predecessor JSON, schema and human projection remains byte-identical.

Apply, learning changes, external export, publication and public release retain their independent authority. No shell, process runner, roaming filesystem, arbitrary network or code-runtime tool is admitted. Existing Run bindings are unchanged; rollback selects a reviewed predecessor rather than editing it.
