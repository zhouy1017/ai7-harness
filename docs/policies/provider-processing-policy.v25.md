# Provider Processing Policy v25

Canonical authority: [v25 JSON](provider-processing-policy.v25.json), validated against its [exact schema](provider-processing-policy.v25.schema.json). This immutable ordinary-production successor of [v23](provider-processing-policy.v23.json) is selected by [active set v17](active-policy-set.v17.json) only when that successor integrates at the intended target. ADR 0094 §1 supplies the selected-binding and explicit synthetic-test authority.

All v23 source, redaction, Run, background, budget, Apply, export and publication boundaries remain. Main and Fast selections are independent. Main and every rule other than Fast 来源译文 retain the existing Go and official DeepSeek admissions. OpenAI `gpt-5.6-luna` and `gpt-5.6-sol` are added only to Fast's 来源译文 contract and the separate fixed connection probe. Other tasks needing tools or native streams stay unavailable before credential release. A catalogue entry or policy eligibility alone never supplies a missing capability.

The separate `explicit-synthetic-model-connection-test` purpose requires an explicit Settings action and exactly one fixed public message and system prompt from the JSON. No Book material, arbitrary question, retrieved source or editor text may enter it. Input is at most 256 characters, output at most 512 tokens, through the proxy, final Egress Gate, one-use adapter ticket, protected broker and existing adapter. Only the sanitized outcome, closed failure code, exact binding and credential-generation metadata, reported usage or explicit unknown, and test timestamp remain; response bodies and secrets are never retained. There is no automatic retry or alternate model. A transport outcome that may have been sent stays unknown.

A saved credential is untested. A successful text probe applies only to its exact channel/model and credential generation; replacement/removal invalidates it. It proves neither tools nor streaming and grants no editorial Task, source access, Apply or publication authority. Existing attempts keep their exact frozen binding; selection and credential generation are checked before and after secret resolution. Schema 84 retains bounded append-only translation-attempt metadata under the existing Material Index owner, including exact source/index/batch identity and reported usage or unknown for failed attempts; it creates no historical attempts and stores no response payload or opaque reasoning.
