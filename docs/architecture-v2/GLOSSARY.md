## Collision guide

| Candidate term | Do not confuse it with |
| --- | --- |
| Primary Agent Harness | AI7 product/runtime authority, Model Provider, or one Codex technical Session. It names the one generic-loop role. |
| Development Reference Framework | A shipped reference implementation, backup harness, or fallback. DeepSeek ships nothing. |
| Primary Agent Harness Adapter | The generic agent loop or AI7 Capability Facade. It translates and contains Codex. |
| Codex Secondary Development | A second AI7 loop or a cloned Codex application. It remains behind the same adapter. |
| Implementation Assumption | Capability evidence, a test gate, or permission to weaken a product requirement. |
| Codex Desktop-like Interaction Reference | A layout, brand, component library, generic chat shell, or coding-agent UI. |

Canonical terms continue to be indexed by the root [`GLOSSARY.md`](../../GLOSSARY.md) and defined by their canonical contexts. This candidate does not redefine Task Ledger, Harness Session Ledger, Execution Binding, Harness Execution Span, Capability Grant, Effect Approval, or Effect Receipt.
