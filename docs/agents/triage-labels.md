# Triage Labels

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on the reporter for information |
| `ready-for-agent` | `ready-for-agent` | Change Brief is complete and a cold Worker can act without expanding scope |
| `ready-for-human` | `ready-for-human` | Requires an owner/Commander decision or other human-only action |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a canonical triage role, apply the corresponding repository label exactly.
