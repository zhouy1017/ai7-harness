# Use Proposal Change Items with explicit atomic groups

AI7 records one independently decidable Proposal Change Item for each semantically independent editorial intent, even when adjacent items share a visual card group or generation origin. The narrow exception is an explicitly named Atomic Proposal Change Group: when partial acceptance would make the Manuscript internally inconsistent, all visible member items receive one indivisible disposition with the dependency and consequence explained. This preserves editor control by default without allowing a superficially granular interface to produce a knowingly incoherent partial result.

> Amended by [ADR 0096 §3](../../adr/0096-edit-manuscript-structure-recognize-structure-and-remove-editor-facing-ceremony.md#3-less-ceremony-more-trust): inline suggestion cards expose one decision system (接受并应用 / 修改后接受 / 拒绝 / 转为批注); reversible draft dispositions remain only in the proposal workspace, with Proposal Decision, Effect Approval and Apply records still distinct.
