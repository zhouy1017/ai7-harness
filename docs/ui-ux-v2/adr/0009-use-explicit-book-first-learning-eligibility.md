# Show automatic local learning and preserve explicit scope overrides

[Root ADR 0094 §3](../../adr/0094-unified-multi-provider-runtime-global-learning-agent-and-word-track-changes-intake.md#3-opt-out-local-learning-with-intelligent-curation) replaces the mandatory unselected Book-first choice for every learning item with disclosed opt-out local collection, intelligent curation and supported-pattern activation. Show collection, scope, recent memory and its decision lineage in `质量与学习`, with global disable, per-Book/material exclusions, narrower reuse and remediation; genuine unresolved choices alone enter `待我处理`.

An automatic eligibility record names its governing basis rather than claiming an editor click. An explicit exclusion or narrower choice wins immediately. A Series learning choice never creates Series Knowledge or bypasses Promotion Review. Learning creates no factual proof, ambient manuscript retrieval, Provider permission, Apply or publication authority; model-driven curation requires the root ADR's separately governed dispatch. Git retains the prior Book-first design and rejected alternatives.

> Amended by [ADR 0095 §7](../../adr/0095-make-procedures-the-central-object-govern-concurrent-execution-and-use-dsh-as-the-complex-task-harness.md#7-the-learning-agent-may-ask-why): reason asks are optional, non-blocking cards with unselected options and optional text, with editor-controlled frequency down to off; they enter the same disclosed learning envelope with lineage.
