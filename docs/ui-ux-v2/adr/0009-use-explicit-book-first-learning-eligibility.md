# Use explicit Book-first Learning Material eligibility

AI7 identifies candidate Learning Material quietly and asks for an editor decision only when one is genuinely required. The decision appears as a Book-grouped attention item and a bounded Learning Material Review Card, not as another question chained to the originating feedback. Every eligibility and scope option begins unselected. AI7 recommends `仅纳入当前图书`; an editor may instead choose an exact named Series, House-wide reuse, explicit exclusion, or deferral after seeing the corresponding future-influence consequence.

Recording inclusion creates only a Learning Eligibility Decision for the exact material/version and selected scope. `纳入当前书系` means only eligibility for Editorial Learning within that named reuse scope; it never means `纳入书系知识`, creates no Series Knowledge Candidate/Item/Revision/Promotion Decision, and cannot bypass Series Knowledge Promotion Review. It may allow later Editorial Learning Signals or Memory Candidates, but it never approves or activates memory, changes Run Source Scope, permits provider egress, establishes factual correctness, trains a Foundation Model, or grants any Effect, workflow, delivery, or publication authority. Explicit inclusion/exclusion outranks inferred eligibility for the exact material, while hidden Policy/Composition assets remain outside editor control.

## Considered options

- Asking every feedback interaction immediately about learning reuse was rejected because it compounds interruption, encourages reflexive consent, and collapses feedback into eligibility.
- Defaulting candidate material to House-wide eligibility was rejected because cross-Book influence would be surprising and difficult to unwind even when all data remains local.
- Restricting all learning permanently to the originating Book was rejected because explicit Series and House editorial knowledge are accepted product capabilities.
- Quiet candidate creation plus an explicit unselected Book-first review was accepted because it minimizes interruption and accidental scope expansion while preserving deliberate broader reuse.

## Consequences

The product needs exact material/version identity, origin/provenance, scope, actor/time, rationale, governing basis, and later Learning Lineage for every recorded decision. Wider-scope choices must disclose their named consequence inline before the single commit action. `稍后决定` remains unresolved rather than negative; `明确排除` preserves the source evidence and history. Only real unresolved decisions enter Global Attention. Aggregation and broader learning eligibility never create an ambient cross-Book browsing or retrieval grant.
