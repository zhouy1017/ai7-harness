# Use a Book-bound DSH-composed Agent Workspace

AI7 provides an explicitly selected agent-primary surface inside one exact Book. AI7 retains the desktop shell, Book and Active Work Object bindings, product records, capability and authority boundaries, visible safety state and direct return route. An admitted DSH composition supplies the inner agent experience and may host compatible admitted DSH UI Plugins.

Explicit entry temporarily gives this **Book-bound DSH-composed Agent Workspace / 图书绑定的 DSH 组合式智能体工作区** the primary central presentation slot. It does not create a new Active Work Object, second Book, global agent home, generic chat root, DSH-owned product authority, Run, grant, Provider permission or manuscript mutation. Leaving the surface restores the prior work presentation without changing its authority or content.

The AI7 shell and Book context remain continuously recoverable even when a DSH UI Plugin renders most of the central surface. A Plugin cannot replace the shell, hide the exact Book/safety state or bypass the one AI7 Apply boundary.

This ADR refines the Book-anchored workbench and Active Work Object presentation without replacing either. Exact geometry, plugin placement/API, compact controls and screen composition remain implementation-facing UI decisions.
