# Use the latest eligible version for new work and preserve historical pins

For a new unpinned Task Skill use, AI7 resolves the newest enabled compatible version within the same stable identity and freezes that exact version before authorization; authorized Runs, Default Execution Rules and existing Workflow Instances never follow later versions silently. A centralized Automation Center projects typed version histories and their linked work/deliveries without creating a generic automation object. Manual removal permanently deletes only never-admitted wholly unreferenced candidates or drafts; a referenced or authority-bearing version leaves a non-executable Historical Version Stub and preserves every authoritative link, trading complete erasure for convenient latest-version use without sacrificing reproducibility or delivery lineage.
