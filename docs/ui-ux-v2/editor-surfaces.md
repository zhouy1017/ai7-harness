Status: **frozen design reference under [ADR 0064](../adr/0064-reweight-repository-development-toward-value-first-delivery.md), adopted as the execution standard for every editor-facing surface by [ADR 0077](../adr/0077-adopt-the-editor-facing-surface-specification-as-the-execution-standard.md) on 2026-09-09.** 本文是实现编辑面时的执行标准：它规定每一屏的最终形态、状态、措辞、需要的数据与对应的后端能力。它不是实现证据；实现状态只记在根 `PROGRESS.md` 与 [E2E journeys](../development/e2e-journeys.md)。交付顺序只记在 [development plan](../development/development-plan.md)。

### Q1 快捷操作（决定 11 / #1330）

范围、类别组合、工序、格式、目标图书与导入关系采用默认值并在本机偏好中记住上次选择；学习准入、书系知识用途等推荐项预选（#1400）；接受、拒绝、结论、风险等级、重导入歧义与关口处置仍不预选。默认只到「准备好、一键可开始」，导入不自动发起模型任务。发起面只留一个开始主按钮，计划是旁边的文字链接；开始仍准备并授权精确计划（#1284、ADR 0096 §3）。确认条只用于取消运行中任务、数据库导入或恢复、存储迁移或清理与永久删除（#1400，ADR 0096 §4.1）；全稿替换、审阅批量应用等可逆操作一键生效并提供撤销（发现中心的跨书批量应用仍先列确切范围再确认）。列表按 2 秒及可见性变化跟随，失败才提供重试；外部服务商的模型目录在凭据就绪时始终提供「刷新模型列表」（#1372）。

DOCX 可拖入书库或稿件页，目标默认当前图书（没有则用文件名建书），关系默认首份稿件（已有稿件则来源材料）；目标、保真、结构与导入按钮同页，详细记录可按需查看。审阅提供「按上次设置再审一次」，新建时保留类别与范围；评估为「开始评估」及「先看计划」，审稿意见在有定稿依据后出现。稿件自动保存，里程碑留在保存菜单；「导出 ▾」直接列 DOCX / PDF / Markdown，记住选项后调起系统另存。

Ctrl+K 搜索命令、按图书与工序发起任务、切换图书与最近完成；Ctrl+Shift+R 新建审阅，Ctrl+Shift+E 开始评估，Ctrl+Shift+T 任务总览，Ctrl+P 切换图书，均在设置 › 键盘列出。任务与发现卡直接提供回答、续行、接受并应用及结果浮窗；发现的批量应用列出确切范围再确认，已读标记不处置待办。无选区的右键任务与提问以当前段落为范围。当前图书任务完成时显示一次可关闭的结果浮窗；跨书连续发起复用 T1 的「发起任务 ▾」sheet 与同一队列。

§7 同步采用一页导入与直接另存；§0.2 的处置不预选、重导入歧义不预选及历史恢复边界保留。

### LAYER-001～008 的收紧读法

决定 1 收紧 ADR 0092 与本节既有的「决定层 / 技术身份层」分离（取代 §0.3、§1 的旧技术详情与切换书稿读法）：生产渠道只渲染编辑可理解的决定层，不渲染技术身份层，也不以「查看技术详情」作为生产模式的替代入口。渠道 / 模型内部标识（模型服务页的手动模型 ID 输入除外，#1372）、策略集、版本与分支名、记录标识、摘要、字节数、百分比小数、精确时间和来源标识等，只有在开发者模式中才可按 LAYER-001～008 的原有规则按需展开；开发者模式默认开，生产模式默认关。因而 LAYER-001～004、LAYER-006～008 的「技术层可达」均解释为开发者模式内可达，LAYER-005 的主操作可达性不变；生产模式的 Journey 只断言决定层，开发者模式的 Journey 才同时断言技术身份层的完整值。

## 配置选择记忆 — Owner #1279 / #1374

配置面暂时改变范围、模式、工序适用性或联网状态时，只禁用或隐藏不适用项，保留编辑已经作出的选择；条件恢复后原样显示。后果预估、开始按钮与提交共同使用当时的有效集合，不把暂不适用项发送给服务。只有编辑取消勾选、明确清除、成功提交后开始新表单，或按 ADR 0087 §4 显式选择固定成员工序，才重设对应选择；重新选择数据库文件等更换精确操作对象的动作也重新开始其决定。

审阅的九类模型审阅旁提供可往返的本地文字检查选择：单独选择本地检查时挂起模型类别，取消后恢复；组合工序仍按其固定成员运行。选章起止、本地数字依据确认及本社词表选用不因隐藏或暂不可用而丢失，保存词表后所选项引用最新可用版本。评估的人工复核与推荐出版保留勾选记忆，只按当前风险条件提交有效值。事实核查的来源排除选择跨决定切换保留，仅补充核查提交排除来源；清空手动模型 ID 恢复此前明确选择的目录模型。

固定成员工序不可拆分提交：暂不可用成员保持勾选并显示原因，在所有成员可用前禁用「先看计划 / 开始审阅」，恢复后仍按工序的完整顺序提交。已选用的本社词表更新读取期间保留原版本并暂停提交，读取成功后改用最新版本。评估的临时勾选记忆以一次表单为界；显式「保存评估」成功后以服务端已存的有效内容重建表单，暂不适用的复核或推荐不会被保存，之后需要时由编辑重新选择；保存失败则保留原表单。

## 后台刷新保持交互 — Owner #1375 / #1383

任务总览、图书任务面板、待我处理、评估、模型服务设置、发现中心及基线/自定义分析与任务抽屉的被动刷新，保留同一条目的展开态、精确控件焦点、未发送输入、光标选择和滚动位置。原条目离开列表时不把这些状态转移给其他条目。原生选择器或已打开浮层使用期间暂缓替换其 DOM；轮询周期不变，普通模式与开发者模式都遵守此规则。

发现中心先对全书发现筛选，再分页；类别、严重度或状态切换回到匹配结果首页，位置轨与批量应用数同属当前筛选集合，不以 40 条窗口或 500 条读取上限代替全书。应用仍需明确确认并沿用现有稿件权限与每请求 500 条的边界；跨请求时分别说明已确认应用、未应用、结果未知与尚未尝试的数量，后续请求失败也保留已确认部分的撤销及未知结果核对入口。应用或撤销结果待确认时，在发现列表前说明原因，暂停新的应用和撤销；只读取原操作结果，核对完成后恢复后续操作。评估的页面标题在空态卡片外，不重复任务行状态；导入同页步骤可导航到「保真与结构」，知识库折叠卡外保留旧版在用/索引警示，普通模式不显示内部版本号。

## Wave 23 direct workflows — Owner #1279 / #1284

The Owner's #1284 outcome supersedes the profile-install, four-step Task Draft promotion and mandatory plan-review passages in §§1, 6, 7, 8 and 9. Every Book immediately has analysis, review, evaluation, writing and Agent capabilities. Starting a task prepares and authorizes the exact plan in one action; plan details remain optional. A production document can be the target of a same-type writing task, pinned to its saved manuscript, branch and version; edits require repinning before execution.

Import fidelity and structure choices appear once; ordinary DOCX degradation uses the standard policy without a required checkbox. Export has inline format/annotation choices and opens the native Save dialog directly. Library additions belong to the current Book, or the house without one, and are immediately referable; custom dimensions and captured procedures are enabled on save. Data and Storage, Quality and Learning, Knowledge Base, Model Service, Series and Evaluation Calibration return to their entry screen, including the concrete Book subpage or Settings.

## Wave 23 Book Agent and dialogue — Owner #1279 / #1285

The Book Agent workspace retains the current manuscript position, accepts whole paragraphs and contiguous paragraph selections, and streams validated candidate items using the admitted Book retrieval tools. Completed rounds, including empty results, allow new instructions immediately; a new round replaces the prior unsubmitted proposals and can refine them. Internal change-set JSON belongs to the workspace and is never rendered as dialogue prose. Submitted independent paragraph suggestions are accepted or rejected individually on their manuscript cards.

The right dialogue drawer has a persistent follow-up composer for the pinned selection and retrievable Book context. Each follow-up retains prior questions and answers in the Harness Session Ledger. `转为修改建议` prefills quoted/fenced replacement text, or the answer itself for editing; the editor still explicitly submits the suggestion and decides its application.

## 去仪式收尾、阅读与修订、局部修改锁定 — Owner #1400 / #1414

本节记录 [#1400](https://github.com/zhouy1017/ai7-harness/issues/1400) 人工测试后的决定：#1401–#1413 已在 `codex/integration-1400` 去除各编辑面仍要求的仪式，#1414 把结果写回本规范，下列 §0.3、§1、§2、§4–§9 已原地改写。权威条款见 [ADR 0096 §4](../adr/0096-edit-manuscript-structure-recognize-structure-and-remove-editor-facing-ceremony.md#4-finish-removing-editor-facing-ceremony-owner-1400--1414)；后端校验、过期守卫、决定记录、事件、Effect 批准与凭据及服务协议均不变，只去掉编辑面的预览与批准点击。

1. **选择即动作**：系统另存 / 文件夹对话框中选定位置即最终导出授权；书系成员与检索排除一键生效；后台处理登记默认首个起点与 100000 tokens 上限、撤销一键；里程碑默认「阶段留档」、空标签自动命名；设为发稿版本默认最新里程碑与「全书定稿 / 编辑审定通过」；新建图书一步完成；审阅批量应用一键并可撤销本批、忽略一键；提案「应用已采纳修改」一步记录并应用；「撤销本次修改」一键；导入、规范文件、词表、导入 Skill、资料库与学习准入一步完成并预选推荐项。
2. **保留的确认**：数据库导入或恢复、存储迁移或清理、永久删除、取消运行中任务各保留一次简洁确认；对稿件内容的判断（采纳 / 拒绝修改建议、评估结论与风险、重导入歧义、关口处置）仍不预选。
3. **普通模式不列「不会做」**：普通模式不渲染「不会做」列表、固定免责句、凭据或法务说教，只留简洁的操作说明与状态，真实失败、阻断与原因照常显示；边界说明归开发者模式技术层与帮助。任务抽屉精简计划为「处理 · 发送 · 会得到 · 中途」四行，写作任务发起面为「会读取 · 会发送 · 费用」，「不会 / 不会做」行只在开发者模式出现。说明对象内容的事实（导出保真的「无法导出」、捕获工序的「不会保存什么」）不是「不会做」列表，照常显示。
4. **阅读与修订**、**查找与替换**、**局部 AI 修改与 🔒 锁定**见 §1；**评估报告优先与维度锁定**见 §5；**侧栏、右缘、卡片、概览与审阅首屏**见 §0.3、§1、§2、§4。

### 0.2 三条总原则（来自 Owner，2026-09-08 / 09）

1. **稿件优先**。「对于中文编辑而言，点开一个稿件，最优先需要被看到的就是上次以工作的稿件本身」——打开有稿件的图书进入稿件上次位置；工作概览是目的地，不是入口（RET-002、IA-012）。
2. **编辑语言，决定层与技术层分开**。「我现在看到的 UI 依旧不是一个中文编辑应该看到的，它更像程序员、工程师或者运维专家的操作面」——生产渠道只说编辑要决定的事；技术身份层仅在开发者模式中按 LAYER-001 ~ 008 收进「查看技术详情」；普通模式不列「不会做」与免责说明（ADR 0096 §4.2）。对稿件内容的处置类选项不预选。
3. **少打扰**。一次性提示用悬浮窗自动消失；不常用的动作收进菜单；任务入口按需呼出；精简模式优先；能自动的（范例归入、索引、备份）不问。

Q1（#1330）：Ctrl+Shift+E 用于「开始评估」，「查看任务」与「专注模式」默认改为 F7 / F8，并在设置 › 键盘列出；已有自定义绑定无冲突时保留。

## 1 · ① 稿件入口

**目的**：编辑打开图书后立刻回到上次工作的稿件位置，在同一个面上读、改、标、发起任务、看结果。

**入口**：书库「打开稿件」、侧栏「稿件」、启动时的上次位置（RET-002）。尚无稿件的图书进入工作概览（①b）。

**最终形态**

- 中央：连续稿件（VIEW-005 排版），阅读区使用更舒适的视口高度，在窄窗口、缩放及辅助面旁保持可用（ADR 0092），段落左缘 3 px 标记线，行内标记高亮；顶部一次性悬浮提示「回到上次位置 / 分析有新发现」自动消失（COPY-015）。
- 右缘一列：四个入口 `导航（大纲 + 查找 / 替换）· 分析 · 任务 · 批注`，图标加简短文字标签并带角标，导航角标只计当前查找命中数（#1409、#1413）；自绘 4px 位置轨带章节刻度、当前位置块及修改建议 / 批注 / 备注三车道，支持指针和键盘跳转，分析未覆盖处单列。原生滚动条隐藏，本地滑块随滚动出现，停止 900ms 后淡出；滚动到窗口边界即平滑续接上 / 下一窗口，并保持正在读的段落在屏幕原位，DOM 仍不超过 32 段；`向前浏览 / 向后浏览` 只是窗口边缘的浅色提示，不是常规阅读方式（#1322、#1329、#1413，ED-008 / ED-015 / ED-059）。
- 辅助面按需参与稿件网格布局：`导航` 展开大纲与搜索，`分析` 展开当前段落相关的人物 / 事件 / 设定；宽度不足时移到正文下方，不覆盖正文或标记卡。生产文档的工作流程栏随可用宽度下移；`任务` 展开任务面（§1.3）。编辑页使用一个视口，正文与辅助区各自滚动，保存状态位于底部操作栏之外（Wave 23 #1287）。
- 稿件顶栏为一行：`修订版 N · 章节位置 · 字数 · 改稿方式 · 段落样式 · 让 AI 修改… · 撤销 / 重做图标`；无分支、百分比、技术详情和保存动作，图书页面跳转由左侧主导航承担（Owner #1314 决定 7、#1322、#1413，收窄 Wave 23 #1287）。正文为居中的独立版心（72ch，约 36 字）。导航面为模式 chips `大纲 / 查找 / 替换`：大纲有自己的筛选框（Enter 逐章跳转，不触发全文查找），全高列出全书各页章节，高亮当前章节，批注 / 建议 / 备注计数大于 0 才显示，空态给出指引；查找框在模式下方，显示 `m / N` 与 ↑ / ↓，Enter / Shift+Enter 跨页循环跳转，结果上下文以 `<mark>` 高亮；替换框紧接查找框之下，`替换当前处` 写成一张已应用的编辑修订卡后跳到下一处，`全部替换（N 处）` 一键完成——服务内部准备、冻结并复核匹配集，在同一个全有或全无的事务中为每一处写一张可单独撤销的已应用修订卡，任何失败都不写入；普通 `撤销` 越过这些应用，替换详情只在开发者模式事后可看（ED-031 ~ 038、ED-062，ADR 0096 §4.4）。不显示「层级 N ·」和排除上限说明。
- 保存菜单「已写入修订日志 ▾」：`保存为里程碑版本…` 等低频动作（ED-052）。
- 批注栏（Wave 24b #1380）由右缘、视图菜单或 F9 切换，按图书记住开关。宽度 ≥1120px 时占独立 300–340px 支撑列；小于 1120px 时沿用 A5 右侧覆盖抽屉，专注模式隐藏；与导航、分析、任务保持单一支撑面。只列当前稿件窗口中可见区域（上下各延伸 200px）的建议、批注和备注，按精确标记锚点与实际卡片高度纵向推开 10px；点正文标记、微章、卡片或将光标停在标记内即选中对应卡片；选中卡片与原文首行对齐并完整进入栏内，前后卡片向上、向下排开；无论是否选中，批注栏独立滚动均能到达每张卡片，滚动不重排或扩大画布。未选中时，正文滚动将批注栏回到顶部并重新对齐原文；其他内容刷新保留当前滚动位置与布局坐标。选中原文、卡片边框和带圆点的实线连接采用同一分类色；正文滚动时跟随，原文离开视口时保留选择并隐藏连线。悬停仅轻量强调，不改变选择；点空白正文或在卡片按 Esc 清除选择。开栏时不另弹浮卡，Enter 与表单操作仍可展开完整卡片（#1451）。未选中卡片为两行紧凑行（300px 宽时典型高度不超过 76px）：首行是无方括号的分类徽章、常驻来源标记与带形状的短状态，次行是单行省略的原文 → 改后或批注 / 备注正文首行，不显示理由、时间与按钮。选中后在栏内展开完整对照、理由、最多两个核心操作及更多，页脚小字为来源标记 · 审阅 / 任务 / 分析 · 时间；回复表单、进行中的操作、恢复凭据或读取待定 / 失败的卡片保持展开。已处理卡片在紧凑态降低文字权重，未处理与未解决冲突保持对比；鼠标按下期间卡片不移动或展开，完成点击后再更新，窗口失焦会解除布局暂停。继续复用更多展开记忆与同一接受 / 拒绝 / 回复 / 处理服务，Enter 与表单入口可回到完整浮卡；后台重读时保留仍在当前窗口的回复节点、焦点与输入法，旧操作暂停至新卡片到达；失败可显式重试，纯滚动不重复读取。同书同稿件同分支的无关结构变化不丢弃仍存标记的草稿，发送期间新输入不被回执清除。收起批注栏只清除栏内拥有的预览；结果待确认时所有修改入口共享原 Effect 的恢复守卫。不持久化任何卡片正文。

## 6 · ③ 任务计划与授权

**目的**：任务共用同一精确计划与授权机制；每个任务都是一份工序的一次运行，计划写明工序版本与阶段（ADR 0095 §1）；高频润色、考据、分析重做，以及计划不可编辑时从表单启动的任何工序，默认在简明「处理 / 发送 / 产出」说明旁一次点击执行，可随时「先看计划」；非即时任务可选「空闲时处理」（ADR 0095 §3、ADR 0096 §3）。点击是本次精确处理与发送的主动授权，预检失败或边界变化先处理；采纳与 Apply 仍是后续独立决定（ADR 0094 §6）。

**入口**：撰写框的 `准备任务`；②A / ②B / ②C / ⑥ 弹层里的 `先看计划`；`快速开始` 不经过此面但同一份计划冻结可查。

## 7 · ④ 导入与保真、重新导入、导出

**目的**：把 DOCX 稿件安全地导进来、再导进来、导出去，编辑看得懂每一类内容会怎样（IMP-001 ~ 057、EXP-001 ~ 024）。

**一页导入**：把 DOCX 拖到书库 / 稿件页或从系统选择框选文件，本机解析与完整暂存，不联网，断电可续（IMP-001/044）。目标默认当前图书或上次目标，无目标时按文件名新建；首份稿件与来源材料按当前图书状态和上次选择预填，重新导入仍由编辑选择；精确匹配只披露，「名称相同，内容不同」不是重复（IMP-018 ~ 021）。目标、关系、书名、保真与结构在同一页，主按钮「导入」准备并提交精确导入记录，「查看导入详情」可按需展开详细复核。同书来源复用与重新导入的来源关系默认选中；选择「直接并入正文」即为确认；重新导入的降级由 `接受降级并提交稿件重新导入` 一步接受并提交（IMP-032，ADR 0096 §4.1）。

保真表仍列内容类、数量、怎样进来、例子和以后导出，三种标记为 `完整保留 / 降级导入 / 不支持导入`。**DOCX 里的东西默认都随来源版本保留**，稿件面编辑正文、脚注尾注与标记，表格与图片只读显示，导出时从原文件恢复，改过的段落在导出记录里逐段说明（ADR 0086、ADR 0096 §1）。没有标题样式时列出不预选的候选章节结构，由编辑确认、调整或不采用；超长段落采用可调整的拆分默认值，不整份拒绝（ADR 0096 §2）。能选的类给 `保留 / 并入` 选项；只有确实无法保留的才要求固定措辞的降级决定 `按上述降级方式导入`，不预选（IMP-002 ~ 005、IMP-055）。导入有业务进度、提交前可取消、一次性提交（IMP-007）；第一次导入进一次工作概览，「打开稿件」为主，分析停在待分析，不自动调用模型（IMP-010/011/051 ~ 053、IMP-056）。

**批注与修订**：批注保留作者标记。检测到插入、删除或移动修订时，导入提交前提供「直接并入正文（作为定稿基线）」与「转为 AI7 修订建议」，默认推荐后者，导入确认提交所显示的方式：前者按所选修订生成初始定稿正文，后者保留修前正文与精确建议卡，待编辑采纳。两条路径都完整保存原 Source Version，并在学习启用且准入时保留修前→修后样本及来源；解析不调用模型，后续归纳按已启用且披露的自动学习授权范围、策略与预检执行，无须每批再次点击。移动与不明确映射先披露处理，不猜测；重新导入继续走比较与冲突流程（ADR 0094 §5）。

导入页的四段 pill 为「选择文件 → 目标与关系 → 保真与结构 → 导入」，仍沿用 Q1 的一页选择与直接提交。文件摘要一行为文件名、格式与段落数，单选为名称加一句业务说明（#1327）。

**作为来源材料导入**：同页展示保存范围并由「导入来源材料」提交；创建来源版本 + 来源导入记录 + 索引；不创建稿件 / 修订版 / 工作流程；不进任务范围；不作事实依据（IMP-031/032）。

**导入草稿恢复**：重启后出现；`继续导入` / `放弃` 不预选；继续前重新核对；原文件不在原位置可从暂存继续（IMP-045 ~ 047）。

**重新导入**：先保存安全修订版（IMP-038）；来源关系已确认时三方比较（来源版本 / 当前修订版 / 新文件），未确认时两方并标 `来源关系未确认`（IMP-039/040）；章节对应表只自动对应精确的，歧义用四个动词 `拆分 / 改写与新增 / 删除 / 并入` 由编辑定、永不预选（IMP-041、IMP-057）；作者修订与批注进来成为标记，编辑自己的标记按对应跟到新修订版，对不上的列出；结果是新修订版 + 稿件重新导入记录，旧的都在（IMP-042）；无变化只记记录不建空修订版（IMP-043）；完成后直接回到稿件，不进工作概览（IMP-056）。

**导出**：当前修订版 / 里程碑版本旁的「导出 ▾」直接列 DOCX / PDF / Markdown（EXP-001/005/006）；`含批注`、`含修改建议（作为修订）` 初始勾选，`含备注` 初始不勾选，格式和选项记住上次选择（EXP-023、MARK-006）。选择格式后直接调起系统另存框，保真说明随导出记录可读；无法导出的项目仍拒绝导出（EXP-007 ~ 009）。在系统另存框选定位置并点「保存」即为最终导出授权，随即一步写出并记录凭据，不再回到界面点 `按上述方式导出`（该按钮只在写入被拒后作为重试出现），系统框取消不写任何文件；审阅报告、审稿意见草稿、图书交付包与数据库导出同样如此（EXP-010、EXP-020，ADR 0038 / 0039 经 ADR 0096 §4.1 修订）。位置由系统选择框选、重名交给系统（EXP-019）；终态 `已导出到所选位置`（EXP-017）；只到本机（EXP-015）。

**数据**：现有 `StagedImportProjection`、`ImportIdentityFindingProjection`、`FidelityCategoryProjection`、`ImportDegradationDecisionReviewProjection`、`ReviewBeforeImportProjection`、`ReviewBeforeSourceImportProjection`、`ReviewBeforeManuscriptReimportProjection`、`ReimportMappingProjection`、`ImportDraftRecoveryProjection`、`ManuscriptImportCommitProjection` 等；需新增：按类的 `保留 / 并入` 选项与「随文件保留」状态；章节级对应与四动词解决；标记跟随对应的结果；导出准备与回执投影（版本 / 格式 / 含不含 / 保真处置 / 目标 / 回执）。

## 8 · ⑤ 全局导航、知识库与设置

### 8.1 待我处理（ATTN-001 ~ 009）

四组固定顺序 `异常与结果待确认 · 等待你的决定 · 运行中与已暂停 · 最近完成`；只有前两组计入角标；每项写书、对象、状态或决定名、原因，右侧按钮写下一步动作，点进去回到它自己的记录。只放跨书事项，书内发现在那本书的「发现」。资料类事项按性质归入四组：外部来源留存失败 → 异常；资料归属与学习准入待定 → 等待你的决定；索引完成 → 最近完成。

[#1324](https://github.com/zhouy1017/ai7-harness/issues/1324)：条目正文两行，首行是衬线书名、对象与状态药丸，第二行是一句不超过 60 字的原因；动作按钮放在右侧，直接写下一步动作，不再另列「安全的下一步：」。长书名、对象与原因按可用宽度省略，完整文字可悬停查看；时间在动作提示中，技术记录只在开发者模式可达。书内与总览的共用任务卡保留类型、标题与药丸、一句进度、时间和现有动作；全书工序单选为名称加一句业务说明。

普通模式不列出跳往开发者专属学习准入页的事项；列表与角标都按本次读取中可见且可到达的事项计数，不改动任何准入记录。质量与学习的普通侧栏入口与返回默认打开审阅偏好（#1377），不提示被收纳页；显式旧链接仍按收纳守卫返回上级并提示。工序与规则的异步读取只有在原加载页仍在屏幕上且开发者模式仍开启时才呈现，离页后的响应不夺回当前页面（#1331）。

运行没有闭合单元（含复用）时显示失败和占多数的缺口原因；部分完成显示警示色「已完成 · N/M 个单元未读成」，任务抽屉与发现顶部显示同一分类原因（[#1307](https://github.com/zhouy1017/ai7-harness/issues/1307)）。结果未知单元仍保留待确认，不自动重发。


### 8.1a 任务总览（#1328 rev 2）

侧栏「任务」紧随「待我处理」，角标为运行中、排队与等你处理之和。跨书页面按正在运行、排队等待、等你处理、已暂停、最近完成排列；图书、类型、完成时间筛选记住上次。任务卡按 §8.1 展示类型、书名与任务标题、状态药丸、一句进度和时间，运行项暂停 / 取消，排队项上移 / 置顶 / 取消等待，待处理项回答 / 处理，暂停项续行 / 改计划重做，完成项查看结果 / 再做一次。更多菜单打开计划、运行或所在图书。

点击卡片在本页打开 500px 的既有任务抽屉，对话直接在抽屉回答；查看结果复用结果浮窗。发起任务使用 A4 非模态 sheet，按快速开始默认配置为多本书连续加入队列，保持打开并累计显示「已加入 N 项」。需要自定义的任务进入本书发起面，并保留返回任务总览入口。暂停全部先冻结队列再逐项暂停，继续全部恢复；队列顺序只存内存，重启按发起顺序恢复。容量满时发起与续行排队，网络、账户与预算限制仍用各自原因。

最近完成默认今天，可选 7 天 / 全部；已有 Run Report 时显示用时与约调用次数，缺少测量时不编造用量或预计。完成提示复用单例 2.5 秒 toast 和已有系统通知设置，点击定位任务并打开结果；本书自动结果浮窗可在发起任务 sheet 关闭。↑↓ / J K 选卡，Enter 打开详情，Space 暂停 / 续行，Delete 显示取消确认条，Esc 关闭详情。`nav.tasks` 注册到现有命令集。

书内任务面使用相同组件按当前书过滤，只列等你处理、进行中、最近完成；保留任务草稿和所选文字的跳转能力。待我处理的运行中与已暂停只列前三项，并链接「在任务总览里看全部」。排队抽屉底栏显示「已记录 · 排在第 N 位 · 查看任务总览」。普通模式不渲染运行标识、策略与模型标识。

### 8.2 书库（IA-008/009、BOOK-006）

完整集合可搜可筛（书名 / 作者 / 责编 / 书系）；每张卡：书名、作者、责编、相关人；稿件一行（修订版 · 上次位置 · 上次工作）；四个计数（审阅 / 评估 / 交付物 / 发现）；`打开稿件`（回到上次位置）为主，`工作概览` 其次；尚无稿件的书 `导入稿件`。作者与责编可多人；相关人从角色清单选（校对 / 美编 / 译者 / 外审专家 / 作者经纪 / 营销 / 其他）。作者、责编是学习归因的维度（FDBK-013）。

### 8.3 书系（SER-001 ~ 029，保留全部）

成员与共享范围一页：成员表（含「书系一致性审阅」列）、书系知识（稳定条目 + 候选 + 冲突；纳入审阅）；检索排除仅开发者模式显示（#1331）。`加入书系` / `移出书系`、`添加检索排除` / `停止此排除` 一键生效，四段影响在点击时计算并随记录保存、可事后查看；选择器默认选中首项，书系知识表单默认选中首个类别与用途；真实书系知识冲突时原地编辑候选或 `保留已披露冲突` 后才能 `纳入书系知识`（SER-003/008/015/022，ADR 0036 / 0037 经 ADR 0096 §4.1 修订）。

### 8.4 知识库（KB-001 ~ 010）

普通模式四类：`审阅规范文件 · 本社审阅偏好 · 范例（按图书）· 资料库`；开发者模式另显示 `评估方案 · 工序与规则 · 外部来源留存`（#1331）。各书的「来源与证据」仍可见。图书与任务只选用、记版本。本社审阅偏好与质量与学习复用同一管理面；质量与学习普通模式提供默认的审阅偏好和反馈记录，学习准入与学习回溯仅开发者模式显示（#1377）。

首页用类别卡呈现当前模式可见的分类，每卡为计数、用途一句与最近条目，下方是最近变化；点击进入分类子页。文件卡收起时最多三行，只留一个查看动作，条款、版本与其他操作在展开后可达。计数受现有分页限制时标「+」，不把当前页冒充全量；外部来源索引尚未提供时如实说明（#1327）。

分类子页提供「返回知识库」回到类别首页，并保留「返回」回到进入知识库前的来源书面；从任务抽屉、审阅配置或待我处理直达子页时同样可返回来源（#1327）。

- 审阅规范文件：来源与原件、编号条款及被引用次数、版本各被哪些审阅用过、哪本书还在用旧版（提示更新）、导入新版本。
- 工序与规则：这是统一的可编辑工序库（ADR 0095 §1），加载时不先显示再覆写静态列表；已有的运行捕获工序在同一目录中保留查看和运行入口（Wave 23 #1287）。预装工序（基线分析、审阅、评估与审稿意见、写作）与本社工序按「能做什么」命名，列出阶段、状态 / 版本 / 用于 / 更新一步之外（REUSE-029/030），提供 `改写为新版本`、`新建工序`、`从本次运行捕获`、`运行此工序…`；`快速开始` 默认执行规则（写明快速开始时会做什么、设立者、时间；查看 / 修改 / 停用）；按类的后台处理登记（哪些非即时工作可在空闲时跑、预算上限、停用）。
- 范例（#1381）：以工作文档与审稿意见条目为主体直接展示，不含图书原稿，不使用「查看范例」折叠墙。首行是类型徽标（工作文档 · 新闻稿等，历史导入与类型筛选用相同称呼；审稿意见保留模板名称）、文档自定义题目与学习准入状态 / 操作；题目缺省或等于类型时用「《来源书名》类型」；次行是来源图书、作者 / 责编与版本、交付 / 导入事实。通过现有有界游标读取完整范例元数据，按类型与来源图书组合筛选后再分页；全部来源图书与类型始终可选，改变筛选回到首个匹配页；本社用 AI7 做的书设为发稿版本后自动归入，学习准入默认「仅本社」，不再询问；以前的书由编辑导入并标明图书、作者、责编。
- 资料库：编辑自行收集的图书、资料、论文、网页；放入即按文件名归入并建索引；归属（某本书 / 书系 / 社级）与学习准入默认选中推荐项，编辑可改，定了任务才能列进「允许参考」（#1410）。规范文件选中文件即导入，本社词表粘贴即并入草稿、`加入并保存词表版本` 同时保存；导入 Skill 一步完成保留、服务校验、安装与选书，受限或被拒的包附原因停止。
- 外部来源留存：审查时落盘的外部资料（SRC-013 的产物）的跨书索引；归属仍在各书的来源与证据；失效的进待我处理；可复用不重复取回。
- 五层索引（KB-009）：原件 · 元数据 · 提取全文（非中文附机器译文）· 分段与页码 / 位置锚点（可引用到句子）· 相似段落检索（向量索引，v1）。索引在本机建；任务选用只读；发送仍受计划边界约束。

### 8.5 质量与学习

Owner #1377 方案 B：普通模式顶部为 `审阅偏好`（默认）与 `反馈记录` 两个胶囊。审阅偏好直接提供本机学习开关和一句说明，待确认候选置顶，可接受或排除；偏好与记忆以正文、适用维度/范围及状态两行显示，可停用，来源与历史按需展开，只显示图书与时间，不显示内部 UUID、SHA 或日志序号。反馈记录仅留图书与来源一行筛选，按时间倒序显示书名、决定摘要、时间与原因两行，可查看原处。普通模式「新增并启用偏好」直接新建规则，范围默认当前图书（在列表中时）或唯一图书，否则为全社（#1408）；学习准入待定项默认选中推荐项，`停止今后使用` 与批量停止一步记录，影响随记录保存（LAUD-006，#1410）。开发者模式保留审阅偏好、反馈历史、学习准入、学习回溯，完整九组筛选与分组、空闲整理 token 预算和手动信号合成表单。底层学习准入、使用范围与记忆语义不变。

开发者模式的学习信号中的 `新建记忆…` 按需展开表单，取消不写入记忆；从所选来源新建记忆也默认收起（Wave 23 #1287）。开发者模式反馈历史按图书 / 来源 / 时间 / 编辑维度分组，并可按作者、责编看；深链到原决定与学习回溯。展示默认自动本地学习的开关、适用范围、按书/材料排除与停止今后使用；学习 agent「主动询问原因」的频率设置（经常 / 偶尔 / 关闭）——询问以选项 + 可选输入出现在核红之后，不阻塞，不预选（ADR 0095 §7）；有效决策约 5~10 次或一批 Word 修订后触发智能去噪、去重、归纳，不强制生成规则。记忆显示正反例、置信度、来源链、状态和监督方向；后续审校/润色/对话检索符合范围的记忆并标出实际参考的规则。仅真实未决事项进待我处理（ADR 0094 §3）。

一级入口「全域智能体（记忆与全局指导）」在未打开书稿时也可用：展示当前学习监督方向、近期记忆与流式对话，提供「指导学习方向」「整理改稿习惯」「跨书检索考据」快捷入口。监督指令立即约束后续归纳/使用并可冻结或修正跑偏记忆；检索明确列出可读书稿、证据、批注范围并尊重排除。进入不授予全库读写、模型发送或 Apply；需要改稿仍回到精确图书（ADR 0094 §4）。

Wave 23 #1286：主操作为「发送问题」，一次点击完成准备与发送；「查看将发送的内容」是可选次级预览，继续与重新回答也直接发起。提问后保留可继续输入的对话区与本会话先前问答。记忆与本次来源共用一套左侧复选框；图书、工序与仍存在的记忆选择（自动跟随修正后的版本；冻结项仍可管理，但不随问题发送）在提问和治理刷新后保留。没有选入图书或工序时使用无工具流式回答。工具名称、监督作用与渠道/模型名称用可读中文与显示名；内部条目、版本、回答标识和原始参数/结果只放在默认折叠的「查看技术详情」。进入全域智能体关闭图书任务抽屉并释放右侧空间，未完成草稿仍留在原图书。


### 8.6 设置

网络代理（#1308）：占位符为 `http://127.0.0.1:端口`，说明本机代理通常使用 HTTP，只有代理本身提供 TLS 入口才使用 HTTPS。保存后向当前所选渠道的模型列表主机探测代理隧道，不携带凭据或稿件；显示「代理可用」「代理不接受 HTTPS 连接，请改用 http://host:port」「代理不可达：端口没有在监听」或「代理要求认证，当前版本不支持」。其他失败沿用「代理不可达：请检查网络代理设置。」；失败不影响保存，上次结论与时间在本次服务会话内保留，关闭代理时清除。

连接测试（#1306）：点击立即显示「正在测试连接…」并禁用测试按钮，返回后通过显示成功横幅，未通过与结果待确认显示错误横幅，取消显示普通提示；横幅包含渠道与模型显示名。未通过按失败代码提示检查 API key、网络或网络代理、模型 ID；当前服务将模型不存在的响应归入 `INVALID_RESPONSE`，此时提示核对模型 ID 与渠道支持情况，不推断更具体的原因。模型行旁保留测试结论，通过与未通过用颜色区分；原始代码仍归技术层，不进入编辑者横幅。不新增自动重试。

设置采用双栏：左侧按「服务 / 编辑工作 / 本机」分组导航，右侧每项设置以约 56px 的行呈现，左边为标题与一句浅灰说明，右边对齐控件，行间使用细分割线；窄窗口导航换行置顶。普通模式提供模型服务、数据与存储、外观、键盘与无障碍、通知、帮助，以及本机分组内一步可达的开发者模式开关。帮助并入「设置 › 本机 · 帮助」，侧栏底部仅保留设置；命令面板与引导页也可进入帮助，返回回到设置首页。使用帮助、隐私与第三方许可正文保持原字节。帮助顶部的开发者模式开关使用同一偏好，初始化成功后才可用，切换立即刷新技术层与导航并保存，不修改模型、收藏、渠道、代理或凭据（#1376 / #1382）。用量、评估校准与预测、诊断仅开发者模式显示，并带灰字「开发者」角标；普通模式进入收纳路由回其上级并提示「该页在开发者模式下显示」（#1331，#1314 决策 1、12）。

普通模型服务完成「选渠道 → 填密钥 → 选模型 → 测试」；普通模式与开发者模式都展示当前主编辑、快速交互的渠道与模型显示名，支持分别指定或「用于主编辑与快速交互」以及手动模型 ID（#1372）。小窗口可纵向滚动；所有配置、角色状态与连接操作必须可见、可聚焦（可用的交互控件）且不被遮挡，不靠隐藏普通模式功能或横向滚动来塞入单屏。联网检索与网络代理在两种模式下均直接展示为可配置区块，保留 #1304–#1306、#1308 的失败反馈与探测结果（#1370）；端点、协议、配置摘要与详细评测指标仅开发者模式展示。键盘与无障碍普通模式只显示只读快捷键列表和本机「减少动效」开关；改绑和 IME 细节只在开发者模式显示。数据与存储的版本与恢复诊断同样只在开发者模式显示。

- 模型服务：统一「选择服务渠道 → 保护输入凭据并拉取模型 → 分别选择主编辑与快速交互模型」；支持刷新列表和手动输入模型 ID，连接测试为可选诊断，不阻塞选择（Wave 23 #1282）；覆盖设计准入的 Zen / Go 与官方服务，未实现或不符合当前策略的条目标明状态。独立角色选择留在本页；工作台及全域智能体顶部不再放模型选择器（#1315）；同一流程内直接填写或更新凭据，提供 `保存并获取模型 / 刷新模型列表 / 测试连接 / 移除凭据`，保存后保持当前渠道和模型；仅显示主编辑与快速交互的当前选择，策略审计信息收在 `查看技术详情`（Wave 23 #1283）。联网检索区分历史评测与当前密钥状态，可在未配主模型时独立测试；首个就绪密钥自动成为默认来源，移除备用来源密钥同时清除备用标记，DeepSeek 支持一键复用官方模型凭据。预算偏好默认不设。连接成功不启动任务或授予 Apply，授权边界变化重新预检并确认（ADR 0094 §1）。模型目录（#1372）：凭据就绪后，普通模式与开发者模式始终可点击「刷新模型列表」，成功保留已选模型，失败沿用 #1304 的明确错误反馈。按名称或 ID 实时筛选，筛选不清除模型选择；普通模式保留选择控件，已选项即使不匹配也仍显示并注明。每个模型可切换收藏，收藏模型置顶；收藏按渠道写入本机 `preferences.json` 的 `model.favourites`，跨重启保留，不进入 SQLite 或数据库导出。开发者模式的单选模型行在固定高度区域内滚动。

## 12 · 设计修订登记

自 ADR 0076 之后由本次会话确认、并由 ADR 0077 写入条款的修订（字母沿用原型说明里的编号）：

- A · AUTH-003 声明改为口语版。B · 计划边界两栏标题。C · 「物质变化」等用词。D · 「不会做」分编辑关心的与技术性的（#1400 起两者都只在开发者模式显示，ADR 0096 §4.2）。E · AUTH-002 主动作改为 `开始任务` / `联网后开始任务`。F · PLAN-001 改为精简 / 完整两种模式。G · 计划预览可编辑并经「更新计划」生成新计划版本。H · 快速开始 = 默认执行规则；运行中只能暂停 / 取消 / 重做。
- I · 设置新增「评估校准与预测」。J · 知识库「工序与规则」页。K · 书库卡片为工作概览的浓缩。L · 范例按图书组织、自动归入。M · 资料库与外部来源留存两类及五层索引（含向量）。N · 图书作者 / 责编 / 相关人字段与学习归因。O · 数据版本与软件版本分开、导出 / 导入数据库、定期自动备份默认关。P · 审阅第 8 类「书系一致性」。
- Q · 重新导入用章节对应表与四个动词。R · DOCX 内容默认保留并给保留选项。S · 原图存来源版本、导出恢复。T · 第一次导入进工作概览、更新版本回稿件。
- U · 写作任务为文档起草入口。V · 文档共用稿件面与标记。W · 里程碑用途四选一（稿件）。X · 发稿 / 交付 / 图书交付包三者分开。
