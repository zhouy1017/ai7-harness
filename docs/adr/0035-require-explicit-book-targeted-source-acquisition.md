# Require explicit Book-targeted source acquisition

AI7 creates a Book-owned Source Version only from an explicit editor action over a supported local file, exact editor-pasted or entered material, or a retention-permitted fully retrieved external research snapshot with exact provenance. Search snippets, failed retrievals, model answers, attachments, and Task use do not create a Source Version by themselves; any Task or evidence retention remains governed by its own record unless the editor separately saves eligible exact material into an explicitly selected Book. An exact existing Source Version identity may be selected only when it is already owned by that same target Book; cross-Book acquisition creates a new target-owned Source Version with its own provenance. When no Book exists, a source-bound Book Creation Draft and Review Before Book Creation may atomically create a zero-Manuscript Book and its first Source Version; the transaction creates no Manuscript, Workflow Instance, Run Source Scope, factual status, Learning Eligibility, or publication authority. A Source Acquisition Record preserves the path, provenance, content identity, target and non-effects; Source Import Record remains its local-file source-only specialization.

## Considered options

Restricting durable sources to local-file import would fragment pasted and externally researched evidence away from the Book source library. Automatically retaining every selected, retrieved, attached, model-produced, or Task-used item would create hidden Book ownership, noisy source history, and ambiguous provenance. Explicit acquisition keeps the library complete enough for professional work while making persistence and later retrieval authority deliberate.
