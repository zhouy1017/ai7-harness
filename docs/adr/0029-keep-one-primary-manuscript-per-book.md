# Keep one primary Manuscript per Book

AI7 permits each Book to own at most one primary Manuscript because a Book is the authority for one intended published work, not a container for peer works. An empty Book may receive its first Manuscript; after that, an external document may reimport into that Manuscript or enter as a Book-owned Source Version, while a distinct intended work requires another Book. This avoids ambiguous workflow, version, mutation-target, and delivery authority inside one Book while preserving multi-part works inside the structure of their single Manuscript.

## Considered options

Allowing multiple peer Manuscripts inside one Book would support collection-like file organization, but it would make the meaning of the Book's primary editable work, Workflow Instance, Task target, milestone, and Publication Version context-dependent. Treating every later document as a reimport would be simpler but would misclassify supporting material and unrelated works.
