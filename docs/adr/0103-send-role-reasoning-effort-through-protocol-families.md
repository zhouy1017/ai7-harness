# Send role reasoning effort through protocol families

The Owner's [#1453](https://github.com/zhouy1017/ai7-harness/issues/1453) E1–E3 decisions require 思考强度 to be declared, selectable and actually transmitted, including tool continuation. This implements that decision after ADR 0102; it grants no development live-call authority.

1. `RuntimeExecutionConfig` is defined once in `src/shared/runtime-execution-config.ts`: optional `modelConnectionId`, `modelId` and `reasoningEffort`. Role defaults and dispatch overrides resolve through it; #1455 can pass the same shape. Provider route documents declare native control and suggested identifiers with documentation sources. Suggestions are not an admission list. A bounded custom identifier reaches the provider; a provider refusal receives an editorial explanation. Unset or `off` omits control and uses the service default, without promising thinking is disabled.
2. Family encoders send Chat Completions `reasoning_effort` (plus DeepSeek's declared thinking toggle), Responses `reasoning.effort`, Messages `output_config.effort` with adaptive thinking, and Gemini `generationConfig.thinkingConfig.thinkingLevel`. Gemini's former unsupported throw retires too; level-to-token-budget translation for older models is not invented. These supersede only ADR 0094's unsupported reasoning-control/continuation dispositions. Historical per-model/live evidence remains historical, not a refusal of configured models.
3. Complete native reasoning items, signed/redacted thinking blocks and thought signatures stay in adapter-private replay state, in native order. Chat preserves `reasoning_content`, including preceding assistant turns. The actual DSH loop carries this state through repeated tool rounds. Its accepted-output digest includes the native bytes, and the final gate binds the exact effort and full payload. Existing frozen system-prompt equality, closed canonical roles, text-only ordinary blocks, tool schemas, provenance, budgets, cancellation, circuit breaking and network/credential boundaries remain. No thinking block is converted into editorial output.
4. Preparation freezes the actual sent effort in the existing execution route; result cards and task rows use that frozen value. Changing a role default cannot relabel old results. Schema 114 adds nullable main/fast role defaults through the existing channel migrator, preserving schema 113 rows and credential references. It does not rewrite historical result JSON. Protocol 202 and package 0.7.0 remain unchanged for wave closure.
5. Automated verification is provider-free, including buffered/streamed multi-round wire fixtures built from the official protocol documentation cited in the provider records. Existing admitted SampleBook fixtures remain. No fixture fingerprint is introduced and no live recording is regenerated; the PR lists request changes and any invalidated developer-live recordings for closure.
