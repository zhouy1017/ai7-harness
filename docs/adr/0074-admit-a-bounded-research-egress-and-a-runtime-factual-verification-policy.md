# Admit a bounded research egress and a runtime Factual Verification Policy for factual review

Plan slice S18 (#53) brings the first factual review of a manuscript: a `factual-review` Task kind on the real path, a contract that lists Manuscript Assertions and judges them, and a research capability that, under `developer-live`, fetches evidence "through the capability facade with the Plan Envelope's search budget and a curated institutional-source list" ([development plan](../development/development-plan.md), [ADR 0066](./0066-add-model-driven-cross-unit-reduction-and-assurance-sampling.md) §Research budget). No such boundary is accepted today. [ADR 0065](./0065-admit-a-developer-live-provider-processing-scope.md) admits transmissions to a model provider and nothing else; the Egress Gate returns `transmit-remote` for a provider payload or refuses; [kick-in 17](../../kick-in/17-source-generation-grounding-boundary.md) states that live external research "would enter through a later accepted boundary covering provider permission, public egress, snapshot provenance, source-quality rules, and deterministic provider-free tests"; and the [Factual Verification Policy](../policies/factual-verification-policy.md) is an accepted design baseline "not connected to a runtime", although V2-UX-FACT-002 binds every displayed factual result to an exact version of it. This record proposes that boundary so that the Owner can accept or amend it before any query derived from a manuscript leaves the developer host.

## Decision

1. **Factual review lands in two steps, and the first needs nothing from this record.** S18a delivers the Task kind, the Factual Review Contract, deterministic Reference Integrity against block text, the ADR 0066 finding record, and a research capability that replays fixtures under `development-ci` and refuses to fetch under every scope with the disclosed state `外部研究未获准`. Until this record is accepted and its slice integrates, every model-judged finding carries the ADR 0066 verdict `未外部复核`, which is the true state: the model raised a question that no admissible evidence has answered. S18c delivers the live path below.

2. **The Factual Verification Policy becomes a runtime Policy Document.** `docs/policies/factual-verification-policy.v1.json`, its schema, and its human projection enter under the rules of the [policies README](../policies/README.md), and active-policy-set v5 pins it as a non-scope-mapped policy beside External Export v1. It carries, as data: the assertion classes of kick-in 17's two-axis model; the admissible evidence kinds in their default precedence with the corroboration minimum per Evidence Assurance Level (`快速整理` records only pending states, V2-UX-EASSURE-004); the outcome set `supported` / `contradicted` / `conflicting` / `unresolved` / `not-applicable` and its fixed mapping onto the six ADR 0066 verdicts; the freshness rule; and the **curated institutional-source list**, each entry a host, a source class, a language, and an authority scope, with Chinese historical and institutional sources present as a required class. Every factual Result Set Revision pins the policy version and digest it was judged under. The Owner reviews the v1 bytes in the slice that writes them before that pull request is Ready; a policy document is never edited by a Worker alone.

3. **Research egress is admitted under `developer-live` only, as a second decision of the one Egress Gate.** The gate that today returns `transmit-remote` or `refuse` gains `fetch-public-source`, so that one owner still decides every byte that leaves the host. Its rules, all of which hold at once:
   - **Origin.** Only inside a newly user-initiated `factual-review` Run under standard Run Authorization, in a developer-live launch bound as ADR 0065 requires. `development-ci`, the E2E Gate, every hosted execution, `fixture-recording`, and `ordinary-production` refuse.
   - **What leaves.** The verification question or query the contract produced for one finding — a manuscript derivative — and nothing else: never a block's text, never a quotation longer than the policy's excerpt bound, never a title, author, or file name, and never anything from a manuscript that is not an admitted Public SampleBook under [ADR 0043](./0043-allow-public-samplebooks-in-repository-and-ci.md). The input rule of ADR 0065 applies unchanged.
   - **Where to.** Only hosts on the policy's curated list, over TLS, with no credential and no account. No open search API exists in v1; discovery on a listed host uses that host's own public search or index pages. A host not on the list is a refusal, not a fallback.
   - **How much.** The Plan Envelope declares a per-Run search budget, allocated by severity tier as ADR 0066 decides; the gate counts every fetch against it, and exhaustion is the disclosed state `研究预算已用尽` on each affected finding, never a silent downgrade and never an unbounded retry.
   - **Capture.** Fetched bytes land only in a Research Snapshot Cache in protected local staging beside the Provider Result Cache of [ADR 0067](./0067-authorize-the-opencode-go-development-credential-with-live-once-testing.md), keyed by the digest of the request, holding the URL, the retrieval instant, the response digest, and the bytes. They are never logged, uploaded, or committed; they reach the repository only as fixtures produced by the fixture-generation tool with human review, and they reach a Book only through the explicit `保存为来源材料` action of S19 with a Source Acquisition Record, as [ADR 0035](./0035-require-explicit-book-targeted-source-acquisition.md) requires. A fetch by itself creates no Source Version.
   - **Provenance.** Every evidence record the contract may cite carries the fields the policy names: issuing body or publisher, URL, publication or update time when the page states it, retrieval time, response digest, the exact supporting passage, access provenance, source-quality assessment, and lineage class. An excerpt that cannot be located verbatim in the captured bytes is not evidence.
   - **Once.** Each live research fetch is a named test item recorded in the ledger of ADR 0067 with the finding it served, so that a fetch is repeated only by a new decision and the cache answers a repeated request.

4. **What the model may and may not do stays as the policy says.** Foundation Model knowledge forms the verification question and chooses among listed hosts; it is never displayed, counted, or recorded as evidence, and it cannot close a finding (policy §Authority boundary 5). Reference Integrity is deterministic and never model-judged. Claim Support and Factual Verification are model-judged only over captured excerpts and are shown as separate states, never as one badge, score, or percentage (V2-UX-FACT-007).

5. **Not decided here.** An open search provider and the credential slot it would need; research on a manuscript that is not an admitted Public SampleBook; research under `ordinary-production`; Series and cross-project evidence scope; the Evidence Comparison Matrix and the rest of the evidence workspace, which follow the UI design session's handoff.

## Consequences

- S18a proceeds on acceptance of nothing: it is provider-free and network-free, and its `未外部复核` verdicts are honest. This record gates S18c only.
- On acceptance, one slice writes Factual Verification Policy v1 (JSON, schema, projection), active-policy-set v5, the `fetch-public-source` decision with its ticket and refusal reasons, the Research Snapshot Cache, the search-budget field of the Plan Envelope, the ledger item kind, and the research capability's live path. The Owner reviews the policy bytes and the curated list before that pull request is Ready.
- The E2E Gate stays network-denied and provider-free: the capability replays fixtures, and a missing fixture is a disclosed gap in the Run, never a fetch.
- Fixtures that quote an admitted Public SampleBook are permitted by ADR 0043; the fixture-generation tool's manuscript-echo refusal gains a kind-aware rule that admits a quotation only when it is a verbatim substring of the admitted unit it is anchored to, which is Reference Integrity applied at generation time.
- A private manuscript gains nothing from this record: its factual review can produce assertions and `未外部复核` verdicts, and no query derived from it leaves the host under any scope.

## Rejected alternatives

- **Start with an open search API.** Rejected: it needs a new credential slot and a provider agreement, it sends the query to a host the policy does not curate, and ADR 0066 already prefers the curated list.
- **Let Foundation Model knowledge close low-risk findings.** Rejected: the policy and V2-UX-FACT-009 forbid it under every assurance level.
- **Fetch under `development-ci` with a recorded allowlist.** Rejected: CI and the Gate must stay network-denied ([ADR 0027](./0027-concentrate-ci-on-e2e-functionality.md), ADR 0065's rejection of widening v1).
- **Retain every fetched page as a Source Version.** Rejected by ADR 0035: acquisition is an explicit editor action, and hidden Book ownership is exactly what it forbids.
- **A fifth operational scope, `developer-research`.** Rejected: the bound is the Run and its Plan Envelope, not the launch; a new scope would duplicate v4's launch form, pins, and ceiling for no new safety property.
- **Defer factual review entirely until this boundary exists.** Rejected: the first step delivers the assertion list, Reference Integrity, and the finding record on real admitted text, and tells the Owner what the model raises before any egress is decided.
