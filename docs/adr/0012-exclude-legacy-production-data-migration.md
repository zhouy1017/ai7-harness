# Exclude legacy production-data migration

The new AI7 starts with an empty production business store and will not import AI7 Reborn Books, manuscripts, indexes, memory, Task/Run/Operation history, workflows, decisions, Effects, receipts, or UI state. The only allowlisted transfers are user-initiated API credentials directly into the target platform's Protected Secret Store through the Credential Broker—Windows Credential Manager or macOS Keychain—reviewed mock-model-provider evidence, and explicitly selected test-only sample Books. This avoids freezing the new domain and Harness ledgers around obsolete schemas or carrying private operational history, while preserving connectivity and the deterministic proof corpus needed to build the replacement; no general legacy-data importer or insecure secret fallback will be created.
