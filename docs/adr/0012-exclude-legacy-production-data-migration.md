# Exclude legacy production-data migration

The new AI7 starts with an empty production business store and will not import AI7 Reborn Books, manuscripts, indexes, memory, Task/Run/Operation history, workflows, decisions, Effects, receipts, or UI state. The only allowlisted transfers are user-initiated API credentials directly from the legacy Windows-protected store into the current supported platform's Protected Secret Store, reviewed mock-model-provider evidence, and explicitly selected test-only sample Books. This avoids freezing the new domain and Harness ledgers around obsolete schemas or carrying private operational history, while preserving connectivity and the deterministic proof corpus needed to build the replacement; no general legacy-data importer or insecure secret fallback will be created. The macOS Keychain destination and cross-platform transfer behavior remain an open platform decision under ADR 0027.
