# Measure editorial quality from editor decisions and gate behavior on it

AI7 owns the quality evaluator the pinned Harness does not provide. Quality Signals are captured from three families: explicit editor feedback on unsatisfied results; editor-authored content as a style reference rather than a pass/fail signal, routed through the Learning Eligibility Policy; and decision and version differences, which are the strongest family because they are behavioral rather than reported. From these come verbatim acceptance rate, revision distance, survival to the delivered revision, dissatisfaction by Editorial Dimension, and workload displacement. Quality and workload are always reported together, because the accepted success criterion is Editor-comparable Delivery Quality plus measurable workload reduction, and acceptance rate alone is perverse — an agent optimizing for it learns to propose safe, trivial changes.

Workload displacement is edit volume weighted by a phase effort weight each Workflow Profile declares once, so a developmental review pass counts for more per unit than a formatting pass. Per-task time tracking is rejected: it needs a baseline that does not exist, is noisy with thinking time, and reads as surveillance to a professional user. Signals are captured globally on the local instance by default and attributed so they can be aggregated per Book, per editor, or per house — but aggregating metrics globally is not granting retrieval access globally, and a Run's ability to read manuscript text remains bound by Run Source Scope. AI7 must operate at N = 0, so no sample threshold may block operation or block an agent from proposing a revision; sample size governs auto-activation alone, below which revisions stay proposal-only and a human decides. Accept, reject, and change reasons are actively queried through a quick non-blocking interaction offering one-click guesses, which must present several alternatives, pre-select none, and track guess-acceptance-versus-correction as its own calibration metric — otherwise the system learns its own suggestion instead of the editor's judgment and corrupts the oracle it depends on.

Two boundaries hold. Editor decisions are ground truth for taste, style, and editorial judgment, and never for factual correctness; an editor accepting a sentence does not make its claims true, so Factual Verification stays evidence-based and separately measured. Privacy is an egress boundary rather than an identity boundary: any authorized person may read a manuscript locally, and Quality Signals may retain manuscript excerpts locally, but no automated path may carry a manuscript off the machine except a configured model call — repositories, hosted CI, runners, artifacts, and logs all remain closed, not because developers are untrusted but because each is a path off the machine.
